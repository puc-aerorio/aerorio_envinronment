# Public prebuilt Image with runtime UID mapping

Team members pull a prebuilt Image from public GHCR (`ghcr.io/puc-aerorio/aerorio-sim`, built by GitHub Actions) instead of building it locally, which took about an hour and failed on slow WSL networks at the ArduPilot clone. A shared Image means the `ardupilot` user's UID/GID can no longer be baked in with `--build-arg HOST_UID`; instead the entrypoint starts as root, remaps the user to the Host's `HOST_UID`/`HOST_GID`, chowns only the small writable paths, and drops privileges. The registry is public so students need no `docker login`. Local `--build` remains for people changing the Dockerfile. Upstream versions (ArduPilot `Copter-4.6.x`, a pinned ardupilot_gazebo commit) are fixed by default and bumped by PR, gated by the test suite.
